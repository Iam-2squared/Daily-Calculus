# 今日の微積

毎日、基礎・応用・難関の微積分問題を解ける学習アプリです。

## できること

- **今日の微積**：毎日、基礎・応用・難関の3問に挑戦できます。選択式の解答、ヒント、解説を用意しています。
- **微積の基本知識**：極限・微分・積分の基本を数式とともに確認できます。
- **学習カレンダー**：正答した日、解いた問題数、ポイント、継続日数を記録します。
- **ランキング**：ユーザーネームとポイントを表示。総合・週間とも最大25人を表示し、圏外でも自分の順位を確認できます。同点は同じ順位です。
- **過去問**：直近30日分の日替わり問題に難易度別で挑戦できます。
- **アカウント**：ユーザーネームと数字4桁のパスワードで登録・ログインできます。

ゲストでも問題を解き、解説を読めます。ポイント・学習記録の保存にはログインが必要です。ランキングに架空のユーザーは登録していません。

## ローカルで起動

Node.js **24以上**を使用してください。組み込みの `node:sqlite` を利用します。

```sh
npm ci
npm run dev
```

ブラウザーで <http://localhost:5173> を開きます。開発時は Vite が画面を、ポート3001の Express がAPIを提供します。通常、開発時の環境変数設定は不要です。

```sh
npm test
npm run build
```

ブラウザーで登録から解答・記録反映・再ログインまで検証するには：

```sh
npx playwright install chromium
npm run test:e2e
```

E2E テストは専用の `data/e2e.sqlite` とポート3100を使用します。

`npm test` は問題の生成・数式、登録とログイン、ポイントの重複防止、週間ランキング、日本時間の日付境界、データの永続化などを検証します。`npm run build` は TypeScript の型検査と画面の本番ビルドを行います。

本番ビルドをローカルの HTTP で確認する場合：

```sh
npm run build
COOKIE_SECURE=false npm start
```

<http://localhost:3001> で確認できます。`COOKIE_SECURE=false` はローカルの HTTP 確認用です。

## Vercel で公開

Vercel の Vite ビルドと Node.js 24 Functions に対応しています。`vercel.json` が静的画面と `/api/*` を同じドメインから配信します。GitHub の `main` と接続すると、以降の更新も自動デプロイできます。

本番の学習記録は Supabase Postgres に保存します。Vercel の一時ファイルシステムには保存しません。Vercel に以下のサーバー専用環境変数を設定してください。`VITE_` などの公開プレフィックスは付けません。

| 変数                       | 用途                                    |
| -------------------------- | --------------------------------------- |
| `SUPABASE_URL`             | 専用 Supabase プロジェクトの API URL    |
| `SUPABASE_PUBLISHABLE_KEY` | 同プロジェクトの publishable key        |
| `CALCULUS_STORE_KEY`       | サーバー専用のランダムな64桁hexキー     |
| `COOKIE_SECURE`            | HTTPS の本番では `true`（本番の既定値） |

`server/cloud-schema.sql` は専用の非公開スキーマと、サーバーだけが利用する固定操作の RPC を作成します。初期設定時、`__CALCULUS_STORE_KEY_SHA256__` をキーの SHA-256 ハッシュに置換して適用します。生のキーや置換後のファイルはコミットしません。テーブルへブラウザーから直接アクセスする権限は付与しません。

Vercel の環境変数は Production に設定します。Preview は別のデータベースとキーを使い、本番の学習記録を共有しないでください。クラウド設定が欠けた Vercel デプロイでは、ローカルDBへフォールバックせずエラーにします。

## ローカル実行とデータ保存

ローカル開発では SQLite を引き続き利用でき、Supabase の設定は不要です。アカウント・セッション・正答記録は `data/daily-calculus.sqlite` に保存されます。

環境変数が必要な場合、`.env` は自動では読み込まないため、シェルから読み込みます。

```sh
cp .env.example .env
# 必要な値を .env に設定
set -a
. ./.env
set +a
npm run dev
```

SQLite を使った常時起動サーバーにも対応します。Node.js 24以上と永続ディスクを用意して `npm run build && npm start` を実行してください。`DATABASE_PATH` で保存先、`PORT` で配信ポートを指定できます。`npm start` は `tsx` を使うため、開発依存も含めてインストールします。

## ポイントと日付のルール

- 基礎は **1pt**、応用は **3pt**、難関は **5pt**。正答時にサーバーで加点します。
- 同じアカウントの同じ問題への加点は1回だけです。復習や同時送信による重複加点を防ぎます。
- 不正解では加点されません。解説を読んで再挑戦し、後から正答することもできます。
- 日替わりは **日本時間の午前0時**。週間ランキングは **日本時間の月曜日午前0時**から集計します。
- 過去問のポイントは、問題の出題日ではなく実際に正答した日の週間ポイントに入ります。
- 継続日数は正答した日を数えます。今日まだ解いていなくても、昨日までの連続記録は維持されます。

## 実装範囲

画面は React / Vite / TypeScript、数式表示は KaTeX、API は Express、保存は SQLite です。問題は日付から決まる **15種類のテンプレートと数値の組み合わせ**で生成します。毎日新しい作問を外部から配信する仕組みや、実際の大学入試問題の収録はありません。テンプレートと数値が一巡すると同じ内容が再登場します。画面の過去問一覧は直近30日、API は過去365日以内の日付指定に対応します。

数字4桁のパスワードは要件に合わせた簡易認証です。ソルト付き scrypt で保存し、セッションは HttpOnly / SameSite / Secure（本番）Cookie を利用します。ユーザーネームとIPアドレス単位でログイン試行を制限します。クラウド版は制限カウンターもデータベースに保存し、複数の Vercel Functions インスタンスで共有します。メールによるパスワード再発行、アカウント削除は未実装です。

## スマートフォンでの操作

スマホを主な利用端末として、下部ナビゲーション、縦並びの問題カード、44px以上の主要ボタン、16px以上のログイン入力欄を用意しています。320 / 360 / 390 / 430px幅で各画面と数式表示を確認しています。カレンダーの日付は7列表示のため、小型端末では幅が44px未満になる場合があります。
